Infraestrutura e Deploy

  • Context engineering se firma como técnica central para agentes de código: relatos de prática mostram um agente alimentado com ~5K tokens de retrieval direcionado superando outro alimentado com um resumo de 100K tokens do mesmo repositório — a Anthropic atribui isso à qualidade do contexto, não ao volume, como fator limitante para conclusão de tarefas.
  • Fine-tuning de pesos abertos: guias de prática de 2026 recomendam QLoRA via Unsloth como receita padrão, testando prompting/RAG antes de decidir por fine-tuning; regra de bolso corrente: RAG para conhecimento que muda, fine-tuning para comportamento novo ou habilidade estreita em modelo pequeno.

  • 3. MCP 2.0 (arquitetura stateless) — A especificação finalizada em 28/07/2026 elimina o handshake de sessão, facilitando balanceamento de carga horizontal para servidores MCP em produção, e formaliza Tasks e MCP Apps. Resultado prático: menos estado por conexão e mais previsibilidade para quem expõe ferramentas via MCP em escala.
  • 4.   • 6. Orquestração multi-agente — Frameworks como o novo Microsoft Agent Framework (Python/.NET, com loop de agente, memória e recuperação de falha) e LangGraph seguem como escolha dominante para workflows multi-agente, com MCP como camada padrão de ferramentas.

Testando 8 modelos, os autores encontram um gap consistente entre "resolver a tarefa" e "seguir as instruções do scaffold". Link
