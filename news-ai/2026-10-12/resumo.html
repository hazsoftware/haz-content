Novidades para Devs

Modelos e APIs

  • Model Context Protocol (MCP) — atualização major da especificação (datada de 28/07/2026) troca o handshake complexo por um núcleo stateless, permitindo colocar servidores MCP atrás de load balancers padrão sem "sticky routing". Passa a exigir validação do parâmetro OAuth iss (proteção contra ataques de mix-up) e cria uma política formal de depreciação (mínimo 12 meses entre anúncio e remoção). Duas extensões viram oficiais: MCP Apps (interfaces interativas dentro do cliente de IA) e MCP Tasks (trabalho assíncrono de longa duração). Segundo o co-criador David Soria Parra, os SDKs do MCP somam hoje ~250 milhões de downloads semanais, dobrando nos últimos 6 meses.
  • GPT-6 / "Intelligent UI" no ChatGPT (rollout iniciado em 07/10/2026, segundo reportagem não confirmada por fonte primária) — a interface passa a gerar elementos interativos (gráficos, botões, formulários) diretamente na conversa; rollout começou nos planos pagos, com Free/Go previstos para 08/10.

Ferramentas e Frameworks

  • CrewAI 1.15.10 (lançado 31/07/2026) — adiciona suporte nativo a MCP e ao protocolo A2A (agent-to-agent), facilitando interoperabilidade entre agentes de frameworks diferentes.
  • LangChain/LangGraph — langchain-core na linha 1.4.x e LangGraph em 1.2.6; o AgentExecutor foi oficialmente depreciado, com migração recomendada para o runtime do LangGraph antes de dezembro/2026.

Agentes e Automação

  • Codex CLI 0.145.0 — evolui o "Multi-Agent V2" com modelos configuráveis por subagente, níveis de reasoning ajustáveis, papéis (roles) definidos e controle de concorrência entre subagentes, útil para quem orquestra times de agentes de código em paralelo.
  • Qodo Gen CLI — framework para criar agentes de código customizados a partir de arquivos de configuração, com agentes pré-construídos prontos para code review e cobertura de testes.

Técnicas e Skills em Alta

  • 1. Context Engineering para agentes de código — otimizar o que entra no contexto do agente (em vez de só aumentar a janela) é apontado como o maior fator de ganho de performance em 2026; um estudo cita 89,1% no SWE-bench Verified via engenharia de contexto otimizada contra 70,7% de baselines manuais (número citado de segunda mão — vale checar a fonte original antes de levar como definitivo).
  • 2. Separação Viewer/Editor (SWE-Edit) — dividir a inspeção de código (viewer) da edição (editor) em contextos separados elevou a taxa de resolução no SWE-bench Verified de 69,9% para 72,0%, cortando em ~60% o contexto passado ao agente principal: técnica direta para reduzir custo de tokens sem perder acurácia.
  • 3. Context Pruning (SWE-Pruner) — poda ativa de contexto irrelevante reduziu de 23% a 54% o uso de tokens em tarefas como SWE-bench Verified, chegando a melhorar a taxa de sucesso em vez de piorá-la, contrariando a ideia de que "mais contexto é sempre melhor".
  • 4. MCP Apps e MCP Tasks como padrão de design — as duas extensões oficiais do MCP (ver seção de novidades) viram técnica de arquitetura: Apps padroniza UI interativa dentro do cliente de IA, Tasks padroniza orquestração de trabalho assíncrono de longa duração — relevante para quem constrói ferramentas MCP que rodam além de uma única chamada.
  • 5. Multi-agente com papéis e concorrência configurável — Codex CLI 0.145.0 e o framework da Qodo Gen CLI reforçam a tendência de orquestração multi-agente com roles fixos (ex. reviewer, tester) e modelos diferentes por subagente, em vez de um único agente genérico fazendo tudo.
  • 6. Interoperabilidade via protocolo A2A — a adoção nativa de A2A pelo CrewAI 1.15.10 soma-se ao MCP como segundo padrão relevante para fazer agentes de frameworks diferentes conversarem entre si; vale acompanhar se vira padrão de facto como o MCP virou para tools.
