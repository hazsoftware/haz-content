Técnicas e Skills em Alta

  • 1. Context Engineering: em 2026 a disciplina virou consenso — o que importa é a curadoria do contexto, não o volume. Um benchmark citado pela Sourcegraph mostra agentes com retrieval direcionado (~5K tokens) superando agentes alimentados com um resumo de 100K tokens do codebase inteiro.
  • 2. AGENTS.md como padrão universal: o arquivo de configuração de contexto de projeto já é adotado por Claude Code, Codex, Cursor, Aider, Copilot, Gemini CLI e Windsurf, consolidando-se como convenção cross-ferramenta.
  • 3. MCP como camada padrão de integração de ferramentas: com CrewAI (parâmetro mcps) e LangChain (langchain-mcp-adapters) plugando servidores MCP direto em frameworks multi-agente, o protocolo se firma como a "USB" de agentes — mas com os problemas de segurança citados acima.
  • 4. DSPy para otimização programática de prompts: em vez de prompt engineering manual, pipelines de produção vêm adotando otimização automatizada de prompts e few-shot examples via DSPy.
  • 5. Avaliação de agentes como disciplina própria (agent eval): ferramentas como DeepEval cobrem avaliação de RAG, teste de agentes, benchmarking e testes de regressão — eval deixou de ser só "rodar o modelo de novo" e ganhou pipeline próprio, separado de testes de software tradicionais.
  • 6. Terminal agents / CLI-first: repositórios como HKUDS/CLI-Anything e o survey acadêmico sobre agentes em ambientes de linha de comando (arXiv 2608.20485) reforçam a tendência de usar o terminal como interface universal para agentes operarem qualquer software.
