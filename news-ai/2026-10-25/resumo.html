Técnicas e Skills em Alta

  1. Protocolo MCP stateless: com a spec 2026-07-28 eliminando o handshake de sessão, servidores MCP passam a ser mais fáceis de escalar horizontalmente e de rodar serverless — quem mantém servidor MCP próprio precisa revisar a migração para a versão 2.0 do SDK antes do fim do ciclo de suporte da versão anterior.
  2. Stacks combinando RAG + fine-tuning + agentes: guias de prática de 2026 descrevem esse tripé como padrão em produção — RAG traz conhecimento atualizado, fine-tuning muda comportamento/estilo do modelo, e a camada de agente decide quando usar cada um; a escolha isolada entre "RAG vs. fine-tuning" já é tratada como falsa dicotomia pela maioria dos times.
  3. Function calling, structured outputs e Responses API como base de produção: guias de skills para 2026 colocam esses três itens como pré-requisito técnico central para quem constrói com LLM, acima de prompt engineering genérico.
  4. Harnesses de execução certificada para agentes: papers recentes (ex. "Certified Execution Harness") propõem controle supervisório via redes de Petri entre a camada de raciocínio e a de ação do agente, limitando formalmente o que um agente autônomo pode executar — resposta direta ao aumento de agentes com acesso a ferramentas de produção.
  5. Avaliação contínua (eval-driven development): ferramentas como DeepEval consolidam LLM evaluation, RAG evaluation, agent testing, benchmarking e regression testing num único pipeline, tratando avaliação como parte do CI/CD e não como etapa manual pontual.
  6. Inference-time scaling sem re-treino: técnicas como "Decoupled Marginal Sharpening" (digest arXiv de 19/10/2026) ganham espaço como forma de melhorar reasoning em tempo de inferência sem custo de fine-tuning, útil quando trocar de modelo base não é opção.
