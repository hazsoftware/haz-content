Infraestrutura e Deploy

  • MCP (Model Context Protocol): a revisão de spec de 28/07/2026 (SEP-2575, SEP-2567) tornou o protocolo stateless no core, removendo o handshake initialize/initialized e o header Mcp-Session-Id — capacidades agora são extensões versionadas e opt-in. Recursos deprecados continuam funcionando por pelo menos 12 meses. Roadmap atualizado em 22/08/2026.
  • pgvector (C) aparece no GitHub Trending de hoje (+17 estrelas) — busca por similaridade vetorial direto no Postgres continua ganhando tração como alternativa a vector DBs dedicados.
  • Padrão de observabilidade para RAG se consolidando como camada própria: tracing de texto da query, IDs/scores de documentos recuperados, contexto passado ao LLM e contagem de tokens — stack comum combina Langfuse + vLLM + FAISS.
  • Consenso prático sobre RAG vs. fine-tuning: RAG para fatos que mudam, fine-tuning (LoRA/QLoRA) para comportamento que não muda — a maioria dos sistemas em produção em 2026 usa os dois combinados, não um ou outro.

Técnicas e Skills em Alta

  • 1. RAG + fine-tuning híbrido: em vez de tratar como escolha binária, times de produção combinam RAG (para fatos que mudam com frequência) com fine-tuning via LoRA/QLoRA (para comportamento e estilo estáveis). É o padrão dominante em sistemas 2026, não a excecão.
  • 2. Fine-tuning eficiente com LoRA/QLoRA: full fine-tuning é considerado caro e raramente necessário em 2026; adaptadores de baixo posto sobre os pesos base dominam, com ferramentas como Axolotl, Unsloth, TRL e LLaMA-Factory disputando espaço.
  • 3. MCP stateless: a migração para a spec 28/07/2026 exige revisar servidores MCP que dependiam do handshake de sessão — quem mantém servidores MCP precisa migrar antes do fim da janela de deprecação (12 meses).
  • 4. Orquestração multi-agente com recuperação de falhas: frameworks como Microsoft Agent Framework e CrewAI agora tratam crash recovery, aprovações humanas e memória como requisitos de primeira classe, não extensões — reflexo de agentes saindo de POC para produção.
  • 5. Observabilidade de RAG como camada própria: tracing span-by-span (query → retrieval → re-rank → generation) com Langfuse, vLLM e FAISS vem substituindo APM tradicional, que não captura falhas específicas de recuperação/relevância.
  • 6. Modelos pequenos especializados (3B–8B) para tarefas de agente bem definidas (suporte, roteamento, sumarização), reduzindo custo de inferência frente a modelos frontier quando a tarefa não exige raciocínio geral amplo.
