Ferramentas e Frameworks

  • Model Context Protocol (spec 2026-07-28 + roadmap de 22/08/2026): a especificação trouxe um core stateless (escala em infraestrutura HTTP comum), Multi Round-Trip Requests, roteamento por headers, resultados de list cacheáveis, hardening de autorização (mais alinhado a OAuth/OIDC) e um framework formal de extensions, incluindo MCP Apps (UI renderizada pelo servidor) e a extensão Tasks para trabalho de longa duração.
  • OpenCode: passou de zero a 120 mil estrelas no GitHub em 2026, expandindo além do core gratuito com planos pagos por uso (Zen) escritos em Go; permite trocar de modelo sem prender o agente a um único editor/assinatura.
  • AccuKnox AgentZ (27/08/2026): nova plataforma para construir, rodar e governar agentes de IA, unificando agente, ambiente de execução, ferramentas, workflows e permissões numa única stack — mira o problema de governança de agentes em produção.

Agentes e Automação

  • GitHub Copilot Workspace: agora suporta múltiplos agentes especializados trabalhando simultaneamente em partes diferentes do mesmo codebase — agentes separados para implementação, testes e documentação, coordenados via uma janela de contexto compartilhada.
  • OpenHands: ganhou tração como alternativa que oferece isolamento forte e controle de recursos para deixar agentes executarem código com mais segurança, frente a ferramentas que rodam agentes sem sandboxing adequado.
  • "Beyond the Chatbox" (Wavespace): framework de interface para agentes que substitui o chat de texto único por generative UI — raciocínio do agente visível, checkpoints de aprovação humana e interfaces específicas por tarefa (formulários, tabelas) em vez de respostas de chat genéricas.

Papers em Tendência

  • Fine-tuning with RAG for Improving LLM Learning of New Skills (arXiv 2510.01375, ICLR 2026): mostra que agentes LLM em tarefas multi-etapa falham de forma previsível (pré-condições não satisfeitas, comandos redundantes, mau tratamento de restrições de ambiente); propõe destilar hints compactos e reutilizáveis a partir de falhas do agente, gerar trajetórias de "professor" via retrieval one-shot no início do episódio, e treinar o modelo aluno nessas trajetórias sem os hints — convertendo retrieval em tempo de inferência em competência aprendida.
  • SoK: Agentic Retrieval-Augmented Generation (RAG) (arXiv 2603.07379): survey que propõe taxonomia, arquiteturas e direções de avaliação para RAG agentic, mapeando o estado da arte de sistemas que combinam retrieval com raciocínio multi-passo.
  • Uncertainty Quantification in LLM Agents (arXiv 2602.05073): mapeia fundamentos e desafios emergentes para quantificar incerteza em decisões de agentes LLM — relevante para quem precisa decidir quando um agente deve pedir confirmação humana.
  • AgentAtlas: Beyond Outcome Leaderboards for LLM Agents (arXiv 2605.20530): propõe avaliação de agentes que vai além de leaderboards baseados só em resultado final, olhando qualidade do processo passo a passo.
  • Automated Benchmark Auditing for AI Agents and Large Language Models (arXiv 2605.26079): framework para auditar automaticamente benchmarks de agentes e LLMs, endereçando contaminação de dados e inflar de métricas em avaliações públicas.
  • Act As a Real Researcher (arXiv 2606.07462): suíte de benchmarks para avaliar LLMs de fronteira e harnesses agentic no ciclo de vida completo de pesquisa (formulação de hipótese, execução, análise) — mede algo além de coding puro.
