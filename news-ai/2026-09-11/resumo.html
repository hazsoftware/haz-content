Técnicas e Skills em Alta

  • 1. Agent orchestration multi-agente: coordenar agentes especializados (implementação, teste, documentação) em paralelo sobre o mesmo contexto, como no GitHub Copilot Workspace e no CrewAI A2A "enterprise-grade" — a fronteira deixou de ser "um agente melhor" e passou a ser orquestração confiável entre vários.
  • 2. Fine-tuning destilado a partir de RAG: em vez de manter um banco de vetores em produção, extrair hints de falhas do agente e destilar em pesos do modelo (arXiv 2510.01375) — reduz latência e custo de inferência ao internalizar conhecimento antes só disponível via retrieval.
  • 3. Evals e observabilidade de agentes: com 66% dos devs (Stack Overflow Survey 2025) gastando mais tempo corrigindo código gerado por IA, evals automatizados, guardrails e checagem de tool-use viraram item básico do checklist de qualquer pipeline com LLM.
  • 4. MCP Tasks / long-running tool calls: a extensão de Tasks do MCP (poll-based tasks/get, novo tasks/update) formaliza como servidores MCP devem expor operações assíncronas de longa duração — relevante para quem constrói ferramentas MCP próprias.
  • 5. UI generativa para agentes: abandonar o chat de texto único em favor de interfaces específicas por tarefa (formulários, tabelas, checkpoints de aprovação), como proposto pelo framework "Beyond the Chatbox" da Wavespace — resposta direta à dificuldade de auditar raciocínio de agente em texto corrido.
  • 6. TypeScript como linguagem dominante para código gerado por IA: TypeScript ultrapassou Python como linguagem mais usada no GitHub; tipagem estática funciona como rede de segurança quando parte relevante do código é gerada por LLM.

Papers em Tendência

  • Fine-tuning with RAG for Improving LLM Learning of New Skills (arXiv 2510.01375) — pipeline que destila retrieval em tempo de inferência em competência aprendida, treinando modelos-aluno em trajetórias melhoradas por hints extraídos de falhas do agente, sem overhead de banco de conhecimento externo no deployment.
  • SoK: Agentic Retrieval-Augmented Generation (RAG) (arXiv 2603.07379) — revisão sistemática de taxonomia, arquiteturas e avaliação de RAG agentivo, mapeando o estado da arte e direções de pesquisa em retrieval multi-etapa controlado por agentes.
  • RigorBench: Benchmarking Engineering Process Discipline in Autonomous AI Coding Agents (arXiv 2606.22678) — em vez de medir só se o agente acertou o resultado final, avalia disciplina de processo de engenharia (planejamento, testes intermediários, revisão) durante a tarefa.
  • Position: Coding Benchmarks Are Misaligned with Agentic Software Engineering (arXiv 2606.17799) — argumenta que benchmarks de coding atuais medem mal o desempenho real de agentes em engenharia de software agentiva, propondo repensar as métricas usadas para comparar modelos como Opus 5, GLM-5.3 e Gemini 3.8.
  • SlopCodeBench: Benchmarking How Coding Agents Degrade Over Long-Horizon Iterative Tasks (arXiv 2603.24755) — mede a degradação de qualidade de agentes de código ao longo de tarefas iterativas de longo horizonte, tema crítico para quem roda agentes autônomos por muitas iterações sem supervisão.
  • Code Review Agent Benchmark (c-CRAB) (arXiv 2603.23448) — dataset e framework de avaliação para agentes de revisão de código, comparando ferramentas open-source (PR-agent) com agentes comerciais como Devin, Claude Code e Codex.
