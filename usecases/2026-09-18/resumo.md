# Usecases de IA — 18/09/2026

- **Claude Code — Impel constrói "um agente para cada função"**: A Impel, empresa que fornece soluções verticais de IA para concessionárias e montadoras automotivas, publicou um case mostrando como usa o Opus 4.5 via Claude para automatizar fluxos de trabalho multi-etapa entre departamentos, sem precisar codificar cada passo manualmente. Segundo Benjy Kest, Chief of Staff da empresa, foi "o primeiro modelo verdadeiramente agêntico" que usaram. Fonte: [Impel Claude case study](https://claude.com/customers/impel)

- **OpenAI Codex — Sam Altman reconstrói seu próprio sistema de mensagens com o Codex**: Altman revelou ter usado o Codex para reconstruir seu sistema de mensagens pessoal e disse estar testando abordagens semelhantes para outras tarefas, incluindo automação residencial. A revelação acompanha o anúncio do "Codex Bot", um assistente sempre ativo nos moldes do Grok Bot, cujo lançamento foi adiado para a próxima semana. Fonte: [Sam Altman says he used an OpenClaw agent to fix an 'unpleasant' daily task](https://www.aol.com/articles/sam-altman-says-used-openclaw-084201418.html) e [OpenAI to Launch Codex Bot Next Week, Rivaling Grok Bot](https://www.kucoin.com/news/flash/openai-to-launch-codex-bot-next-week-rivaling-grok-bot)

- **Google Antigravity — novo harness antigravity-preview-09-2026 com Files API e Credentials API**: O Google lançou uma atualização do harness de agentes gerenciados do Gemini, rodando sobre o Gemini 3.8 Flash, trazendo uma Files API para upload e gestão de arquivos em sandboxes e uma Credentials API que permite conectar agentes a serviços como GitHub e Slack sem expor tokens ao modelo. A empresa reporta 40% menos tokens de saída em alterações de arquivo e até 6% mais conclusão de tarefas em cenários multi-turno de engenharia de software. Fonte: [Google's Gemini Agent Update: 22% Efficiency Boost, Files API, and Credentials API Live Now](https://nokiapoweruser.com/google-gemini-agents-update-antigravity-harness-apis/)

- **OpenClaw — a base por trás do futuro "Codex Bot" da OpenAI**: A OpenAI contratou Peter Steinberger, criador do OpenClaw, e está construindo o "Codex Bot" (assistente sempre ativo em apps e sites) sobre a tecnologia do projeto. Sam Altman afirmou que "código mais uso generalizado do computador" é uma combinação que veio para ficar, reforçando o papel central do OpenClaw na estratégia de agentes da OpenAI. Fonte: [OpenAI to Launch Codex Bot Next Week, Rivaling Grok Bot](https://www.kucoin.com/news/flash/openai-to-launch-codex-bot-next-week-rivaling-grok-bot)
