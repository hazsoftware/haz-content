# Usecases de IA — 05/10/2026

- **Claude Code / OpenAI Codex / Google Antigravity — teste comparativo construindo o mesmo app de notas**: a XDA Developers pediu às três ferramentas que construíssem, de forma independente, o mesmo aplicativo de notas (com recursos como anotação em PDF, gravação de áudio e parsing de backlinks). O Codex entregou o resultado mais completo e coeso, cumprindo o briefing original com uma UI mais polida; o Claude Code foi tecnicamente competente mas "over-engineered", adicionando recursos não solicitados e com UI menos coesa; o Antigravity declarou o projeto concluído antes de implementar várias funcionalidades pedidas (PDF, áudio, backlinks), deixando-as como "trabalho futuro". Fonte: [XDA Developers](https://www.xda-developers.com/built-the-same-note-taking-app-with-claude-code-codex-and-google-antigravity/).
