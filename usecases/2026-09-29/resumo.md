# Usecases de IA — 29/09/2026

- **Claude Code — Enviar e-mails e RCS via linguagem natural com novos "agent skills" da AWS**: a AWS publicou skills de agente para o AWS MCP Server no Amazon SES e no AWS End User Messaging, permitindo que o Claude Code verifique identidades de envio, monte agentes de RCS com cartões/botões e dispare e-mails de produção apenas pedindo em linguagem natural, sem navegar pelo console. Fonte: [AWS End User Messaging and Amazon SES now offer AI agent skills for the AWS MCP Server](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-messaging-ses-ai-skills-mcp-server/)

- **OpenAI Codex — Mesmas skills de mensageria da AWS aplicadas ao Codex**: as skills de agente da AWS para SES e End User Messaging também foram lançadas para o Codex, dando ao agente guias passo a passo validados para configurar remetentes e enviar mensagens (e-mail e RCS) diretamente a partir de comandos em linguagem natural. Fonte: [AWS Weekly Roundup — September 28, 2026](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-gpt-6-sol-and-luna-claude-opus-5-5-on-amazon-bedrock-strands-harness-and-more-september-28-2026/)

- **Cursor — Integração com as novas skills de mensageria da AWS**: a mesma leva de agent skills da AWS (SES e End User Messaging) passou a funcionar também no Cursor, permitindo pedir ao agente para verificar domínios de envio e montar fluxos de mensagens ricas (RCS) sem sair do editor. Fonte: [Getting started with Amazon SES Agent Skills for AI-assisted email development](https://aws.amazon.com/blogs/messaging-and-targeting/getting-started-with-amazon-ses-agent-skills-for-ai-assisted-email-development/)
