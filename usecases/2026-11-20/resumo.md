# Usecases de IA — 20/11/2026

- **OpenAI Codex — "Performance Factory" corrige lentidão do ChatGPT automaticamente**: a OpenAI revelou um sistema interno em que agentes Codex investigam alertas de lentidão do ChatGPT, fazem a causa-raiz do problema e, após passar por uma revisão adversarial entre agentes, abrem um pull request com a correção. Em pouco mais de três meses o sistema rodou mais de 1.700 investigações e resolveu a causa-raiz em mais de 600 casos. Fonte: https://venturebeat.com/orchestration/exclusive-openai-reveals-performance-factory-a-codex-powered-software-optimization-system-that-keeps-chatgpt-fast

- **Claude Code — "Code Mode" encadeia chamadas de ferramentas via JavaScript**: a Anthropic lançou (experimental, opt-in) o Code Mode no Claude Code, que faz o próprio Claude escrever JavaScript para encadear várias chamadas de ferramentas em uma única etapa, rodando comandos em paralelo e retornando só o resultado necessário — reduzindo uso de tokens em fluxos com muitas chamadas de ferramentas. Disponível a partir da versão 2.1.323, em sessões interativas de terminal no build nativo. Fonte: https://dataconomy.com/2026/11/19/anthropic-adds-code-mode-to-claude-code-for-chained/

- **Google Antigravity — Plugin de robótica com Gemini 4 Hydrogen**: o Google lançou um plugin de robótica para o Antigravity que usa o modelo Gemini 4 Hydrogen para configurar braços robóticos, simular em MuJoCo e permitir controle conversacional de hardware compatível, ampliando o uso do Antigravity para além de tarefas puramente de codificação. Acesso requer assinatura paga do Google AI Pro ou Ultra. Fonte: https://thedefiant.io/frontier/ai/google-launches-gemini-robotics-plugin-for-antigravity
